# Source Summary

## What It Covers

- Murata identifies common-mode choke coils as filters that reduce common-mode noise
- Murata scopes them to differential transmission lines, power lines, and audio lines
- Murata frames the intended use as suppressing common-mode noise while preserving the wanted signal
